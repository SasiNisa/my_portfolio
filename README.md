#  Portfolio Website

## **About**

A personal portfolio website showcasing my projects, skills, and coding journey and is designed to demonstrate both frontend and backend development skills.

The site is designed with modern web technologies and deployed on shared hosting with automated CI/CD pipelines.

---
## 🚀 Tech Stack

- **Frontend:** HTML, CSS, JavaScript  
- **Backend:** PHP (with OOP concepts)  
- **Data Handling:** JSON for backend–frontend communication  
- **Version Control:** Git & GitHub  
- **CI/CD:** GitHub Actions for automated deployment  
- **Hosting:** Bluehost (via FTPS)  

---

### 🛠 Software Development Life Cycle (SDLC)

- **Requirement Analysis:** Defined portfolio goals (showcasing projects, skills, contact form, responsive design).  
- **Design:** Created layout wireframes and navigation flow; planned sections like Home, About, Services, Projects, and Contact.  
- **Implementation:** Developed front-end with **HTML, CSS, JavaScript**, and styled with **Bootstrap**; structured reusable components (navbar, footer, sections).  
- **Testing:** Verified responsiveness across devices and browsers; tested navigation links, forms, and interactive elements.  
- **Deployment:** Deployed to hosting server using **cPanel/FTP**.  
- **Maintenance:** Updated project details, improved UI/UX, and added new features over time.  
 


## ⚙️ Features

- Clean, responsive design for web and mobile  
- Projects and portfolio showcase with structured layout  
- Reusable components (navbar, footer, project cards)  
- JSON integration for dynamic content  
- Automated deployment using GitHub Actions  

---

## 🛠️ CI/CD Workflow

1. **Code Push** → Commit & push changes to GitHub repository  
2. **GitHub Actions** → Triggers CI/CD workflow  
3. **FTPS Deployment** → Automatically uploads updated files to Bluehost (`/public_html/sasihub/`)  
4. **Live Update** → Website reflects latest changes without manual upload
