# 🌐 Portfolio Website

## **About**

This is my personal portfolio website built using **PHP, HTML, CSS, and JavaScript**.  
It showcases my **projects, skills, and other works**, and is designed to demonstrate both **frontend and backend development skills**.

The website also serves as a demonstration of my **CI/CD setup**, where any updates pushed to GitHub are automatically deployed to the hosting server.

---

## **Features**

- Clean and professional design  
- Projects page with **Add/Edit/Delete functionality** (admin-side)  
- Skills page with database integration  
- Responsive layout for desktop and mobile  
- CI/CD enabled deployment from GitHub (SFTP/SSH)

---

## **Technologies Used**

- **Frontend:** HTML, CSS, JavaScript  
- **Backend:** PHP 8  
- **Database:** MySQL  
- **CI/CD:** GitHub Actions with SFTP deployment  
- **Hosting:** Bluehost / Render (for demonstration)
